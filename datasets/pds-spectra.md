# NASA PDS Geosciences Node Spectral Library

PDS: Planetary Data System

[link](https://pds-speclib.rsl.wustl.edu/)

RELAB: NASA Reflectance Experiment LABoratory database, produced at Brown University, hosted by the PDS Geosciences Node.

The NASA Reflectance Experiment LABoratory (RELAB) database includes spectral measurements of a wide range of *terrestrial* and *extraterrestrial* materials spanning UV to far-IR wavelengths.

PDS Data products are freely available to the public.

The user will receive an email with direct links to download the packaged file and corresponding md5 checksum file. The checksum file can be used to confirm the file integrity of the requested files.
